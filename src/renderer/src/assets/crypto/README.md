# Chain and token marks

The SVGs in `chains/` and `tokens/` are the branded marks from
[web3icons](https://web3icons.io) (`@web3icons/core` 4.0.58), by 0xa3k5, under the
[MIT licence](https://github.com/0xa3k5/web3icons/blob/main/LICENSE). Each file is the
package's SVG string as published, with only its `class` attribute removed.

| `chains/ethereum.svg` | networks/branded/ethereum |
| `chains/base.svg` | networks/branded/base |

| `chains/aptos.svg` | networks/branded/aptos |
| `chains/ton.svg` | networks/branded/ton |

| `tokens/<symbol>.svg` | tokens/branded/`<SYMBOL>` |

They name a chain or a token and nothing else: no mark here stands for an
endorsement.
